# REWAQ Location

Approved naming direction: REWAQ Location. Proposed marketing expansion: **Rent Easily With Accurate Quotes**. This is a constructed brand meaning, not the original meaning of the architectural word riwaq/rewaq.

The new symbol uses a Marrakech-inspired arch, an R monogram, a route through its leg and a destination marker. It replaces the former L symbol. Palette retained: forest #103E38, terracotta #C86A4A, sand #E8D6BA, ivory #FAF7F1 and ink #263C36.

Contents: SVG logo variants, transparent high-resolution PNG logo variants, symbol variants, and app icons at 16/32/64/180/512 px. Existing LOCATION and Medina Motion files are retained separately as historical drafts.

Public web and admin branding are updated. Database name `location`, internal session identifiers and historical booking references are intentionally preserved. Naming adoption does not constitute trademark, company-name or domain availability clearance.
